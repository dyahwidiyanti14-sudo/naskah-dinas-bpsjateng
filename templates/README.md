Taruh 4 file template di sini, dengan nama persis:

- memorandum.docx
- nota-dinas.docx
- surat-tugas.docx
- surat-dinas.docx

Ambil dari folder Google Drive template kamu, pastikan placeholder ditulis
sebagai `{nama_field}` (huruf kecil, gunakan underscore, tanpa spasi) agar
tampil rapi sebagai label form, misalnya `{nama_pegawai}`, `{nomor}`,
`{perihal}`, `{tanggal}`, `{isi_surat}`, dll.
